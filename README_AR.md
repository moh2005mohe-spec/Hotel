### الخطوات:

1. **افتح Supabase:**
   - اذهب إلى https://supabase.com
   - سجل الدخول لمشروعك

2. **افتح SQL Editor:**
   - انقر على **SQL Editor** من القائمة الجانبية
   - انقر على **New Query**

3. **انسخ الـ SQL Code:**
   - افتح ملف `MIGRATION_INSTRUCTIONS.md` من المشروع
   - انسخ محتوى الـ SQL

4. **الصق وتنفيذ:**
   - الصق الـ SQL في SQL Editor
   - انقر **RUN** أو **Ctrl+Enter**

5. **التحقق:**
   - إذا رأيت "Success" بدون أخطاء، فقد تم التطبيق بنجاح
   - إذا حدث خطأ، اقرأ الرسالة بحذر
